## 重构记录(纯净改进)

实现图像转换时发现架构问题:`compute_output_path`/`compute_extract_dir` 原在 archive.rs,但路径计算是通用需求(图像也用),且 fs_util 整体 gate archive 导致图像 IO 无法独立。重构:

1. **新建 `path.rs`**:从 archive.rs 迁出 `compute_output_path`/`compute_extract_dir`/`split_path`/`strip_last_ext`/`join_path` + 测试。纯字符串逻辑,无 feature gate,各域复用。
2. **fs_util 函数级 gate**:通用 helpers(`write_bytes_create_new`/`write_bytes_safe`)无 gate;archive 函数 gate `archive`;image 函数 gate `image`。图像转换现可独立于归档(`default-features=false, features=["image"]`)。
3. **archive.rs 瘦身**:移除路径函数与测试(迁 path.rs),专注归档纯逻辑。
