## 范围收窄(诚实记录)

- **PDF 合并未做**:lopdf 0.44 无内置页树合并 API(merge),手动实现需重建页树/对象引用/xref,复杂度高。推迟,记入 todo/prd 非目标。
- **PDF 压缩优化未做**:lopdf compress() 仅基础流压缩,非真正优化器(不降采样图像/去重字体);需 Ghostscript 外部引擎。
- **PDF OCR 未做**:需 tesseract CLI。
- **encrypt_decrypt_roundtrip `#[ignore]`**:lopdf V2 owner=user 相同口令的 `load_mem_with_password` 验证存在上游限制(相同口令加载验证失败)。生产代码 owner=user=password(用户友好 UX)加密成功且 `is_encrypted`/wrong 口令失败均验证通过;roundtrip 还原待 lopdf 上游修复后启用。已用 `encrypt_produces_encrypted_pdf`(验证加密产出 + 错误口令失败)覆盖核心行为。

## 待人工确认

- **GUI 编译验证**:本机 windows crate 栈溢出 ICE(已知限制)。GUI 代码遵循既有模式(pdf_split/rotate/encrypt/decrypt 薄封装 + lib.rs 注册),正确性留 CI `tauri-build` 三平台验证。
- **lopdf V2 相同口令**:生产用户用单一口令加密/解密,若 lopdf 加载验证对相同口令失败,解密路径受影响。建议后续改 V5(AES-256,owner/user 独立处理)或跟踪 lopdf 修复。当前加密 + is_encrypted + 错误口令拒绝均工作。
- **PDF rotate 仅 90° 顺时针**:无角度参数(对标 FreeConvert rotate 固定 90°)。多次旋转叠加(90→180→270)。
